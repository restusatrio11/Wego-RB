# 0002. Didone Display Wordmark and All-Lowercase Branding

## Context
Berdasarkan identifikasi tipografi referensi acuan (*ilovecreatives*), wordmark utama menggunakan tipografi Didone ekstrem dengan kontras vertikal tebal dan garis horizontal *hairline* setipis silet, proporsi kondensed ramping, serta format *all-lowercase* (`ilovecreatives` dan `@ilovecreatives`).

## Decision
1. **Didone Display Font**: Menggunakan **Bodoni Moda** (Google Fonts) dengan parameter display optik penuh (`opsz: 96`, `wght: 800`) dan *negative tracking* (`letter-spacing: -0.05em`) untuk wordmark hero dan display footer `@bpsprovsumut`.
2. **Wordmark All-Lowercase**: Menggunakan format huruf kecil penuh `wegoberbagi` sebagai brand wordmark raksasa di hero cover untuk menciptakan kesan kontemporer, santai, dan konsisten dengan acuan.
3. **Kepanjangan Resmi**: Kepanjangan resmi program ("wadah edukasi dan gagasan optimal") disandingkan sebagai subtitle elegan tepat di bawah wordmark, menjaga legibilitas kepanjangan tanpa mengorbankan estetika display satu kata.
